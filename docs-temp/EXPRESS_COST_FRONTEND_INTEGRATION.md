## 🚀 快速启动

### Step 1: 确保后端服务运行

后端服务需要运行在端口 3002（根据 `.env` 配置）：

```bash
cd d:\Github\logix\backend
npm run dev
```

**注意**: 如果端口 3001 被占用，请检查 `.env` 文件中的 `PORT` 配置。

### Step 2: 启动前端服务

```bash
cd d:\Github\logix\frontend
npm run dev
```

前端服务将运行在 `http://localhost:5173`（或配置的端口）。

### Step 3: 访问新功能

1. 登录系统
2. 在左侧导航栏找到 **"尾程"** 菜单
3. 点击子菜单：
   - **快递费规则导入**: 上传 Excel 规则文件
   - **快递模型试算**: 进行费用试算

## 🔗 API 端点映射

前端调用的后端 API：

| 功能         | 方法 | 端点                                           | 说明                |
| ------------ | ---- | ---------------------------------------------- | ------------------- |
| 导入 Excel   | POST | `/api/v1/express-cost/import-excel`            | multipart/form-data |
| 试算费用     | POST | `/api/v1/express-cost/calculate`               | JSON body           |
| 获取承运商   | GET  | `/api/v1/express-cost/carriers?countryCode=US` | 按国家筛选          |
| 获取版本列表 | GET  | `/api/v1/express-cost/versions`                | 所有版本            |

## 🔍 故障排查

### 问题 1: 导航栏不显示"尾程"菜单

**原因**: 浏览器缓存旧的路由配置  
**解决**: 硬刷新页面（Ctrl + Shift + R）或清除缓存

### 问题 2: API 调用失败

**原因**: 后端服务未启动或端口配置错误  
**解决**:

1. 检查后端是否运行: `curl http://localhost:3002/api/v1/express-cost/versions`
2. 确认 `VITE_API_BASE_URL` 环境变量正确

### 问题 3: 图标不显示

**原因**: Element Plus 图标未正确导入  
**解决**: 检查 Layout.vue 中是否导入了 `Calculator` 和 `Van`
